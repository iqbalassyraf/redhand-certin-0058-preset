redhand-certin-0058-preset 0.2.0

A deterministic runtime interceptor that stops AI agents from moving money the way CERT-In CIAD-2026-0058 (CRAFTY FALCON) and CIAD-2026-0049 describe. It sits on the tool-execution boundary, so a manipulated agent cannot reach a payment tool except through it. No model is in the decision path.

Every number below is produced by a command in this repository. The last section lists them.

What it does

  • Pins each agent run to one environment and one tool list with an Ed25519 token, so a staging credential replayed against production, or a tool the run was never granted, is refused.
  • Detects micro-transaction probing, enumeration bursts, recon-then-payout sequences, split payments across runs, payees and currencies, and slow drains against a rolling cap.
  • Requires a signed, single-use approval for a high-value or new-beneficiary payment.
  • Writes every decision to a SHA-256 hash chain that verifies offline.
  • Ships 17 documented rules, each with its severity and whether it can be tuned or waived.

Results on the replay corpus

The corpus is synthetic: 108 scenarios written to exercise each rule, of which 73 are attacks the preset should catch and 26 are ordinary traffic.

  • The preset stops 73 of 73 attacks (100.0%): every expected rule fired.
  • It wrongly flags 0 of 26 benign scenarios.
  • 5 attacks are documented gaps the preset does not catch, by design, and 4 benign cases are documented false positives. Both are listed in the detection results rather than hidden.

A full score on a corpus we wrote ourselves is a regression check. It shows each control does what it claims on the cases written down. It does not measure performance on real traffic.

What it does not do

  • It runs in the agent's process. An attacker with code execution can bypass it and a stolen signing key mints valid tokens. Run tools behind the out-of-process gateway or a sandbox.
  • It judges the argument fields you bind to each tool; a money-moving argument nobody bound is not judged.
  • The first micro-probe looks like a small legitimate payment. The breaker trips on the second.
  • The M4.2 finding schema and M4.3 mode semantics were implemented from design specifications and are not certified by RedHand.

The full list is in the threat model.
