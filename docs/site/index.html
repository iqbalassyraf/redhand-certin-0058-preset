redhand-certin-0058-preset

A deterministic, fail-closed runtime interceptor for AI-agent tool calls in fintech and BFSI environments, built against CERT-In advisories CIAD-2026-0058 (CRAFTY FALCON) and CIAD-2026-0049 (AI agents as attack vectors). It sits on the tool-execution boundary, so a manipulated agent cannot reach a payment tool except through it. No model is in the decision path.

What it gives you

  • Pinned identity: Ed25519 run tokens bound to one run, one environment and a fixed tool list.
  • Behavioural breakers: micro-transaction probing, velocity, recon-to-payment sequences, structuring across runs, payees and currencies, rolling cumulative caps.
  • Human approval where it counts: per-transaction signed approvals with single-use nonces.
  • Evidence: a SHA-256 hash-chained audit log, verifiable offline, plus an HTML evidence report.
  • A safe rollout path: observe-only mode records would_have_blocked before you enforce.

Honest limits

It is an in-process control: a host that is fully compromised can bypass it, so run tools behind the out-of-process gateway or a sandbox. The threat model lists every limit.
